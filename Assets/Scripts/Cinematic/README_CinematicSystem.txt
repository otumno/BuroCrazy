1. ОБЗОР СИСТЕМЫ
================================================================================

Cinematic Graph System - это визуальная система постановочных сцен, аналогичная
Dialogue Graph. Она позволяет создавать последовательности действий (движение,
речь, диалоги, управление камерой, UI, события) в виде графа узлов.

Структура файлов:
- Assets/Scripts/Cinematic/                    - основные классы
- Assets/Scripts/Cinematic/Nodes/              - типы узлов
- Assets/Scripts/Cinematic/Editor/             - редактор графов
- Assets/Scripts/Cinematic/Installers/         - Zenject installer

================================================================================
2. УСТАНОВКА НА СЦЕНУ
================================================================================

Шаг 1: Откройте сцену GameScene (или другую главную сцену).

Шаг 2: Создайте пустой GameObject и назовите его "CinematicSystem".

Шаг 3: Добавьте компоненты на этот объект:
  - SceneObjectRegistry
  - CharacterRegistry
  - CinematicPlayer

Или используйте меню: GameObject -> Create Empty и перетащите скрипты.

================================================================================
3. СОЗДАНИЕ РЕГИСТРОВ
================================================================================

SceneObjectRegistry
-------------------
Этот компонент связывает строковые ключи с объектами сцены.

1. Выберите CinematicSystem в иерархии
2. В инспекторе найдите список "Entries"
3. Добавьте записи для каждой точки:

   Ключ                 | Объект на сцене
   ---------------------|--------------------------------
   EntryPoint           | Точка входа персонажа
   FirstStopWaypoint    | Первая остановка
   SecondStopWaypoint   | Вторая остановка
   DirectorChairPoint   | Точка у кресла директора
   DeskButton           | Кнопка стола директора (UI)
   WaitingZone          | Зона ожидания
   ExitWaypoint         | Выход

4. Альтернатива: нажмите "Auto-fill from scene" для автоматического
   заполнения (добавит ВСЕ объекты со сцены).

CharacterRegistry
-----------------
Регистрирует персонажей по ID:
  - "Director" - игрок (DirectorAvatarController)
  - "Staff:Имя" - сотрудник по имени
  - "Client:0" - клиент по индексу

Обычно не требует ручной настройки - персонажи регистрируются автоматически.

================================================================================
4. СОБЫТИЯ (КАТСЦЕНЫ): ЕДИНЫЙ ПАЙПЛАЙН
================================================================================

Любая катсцена — туториал, визит Инспектора, сюжетная сцена — это обычное
событие: запись в списке Triggers компонента CinematicTriggerManager
(GameScene). Особых веток в MainUIManager/EndingManager для запуска графов нет,
сами они CinematicPlayer.Play() не вызывают.

Добавление события:

1. Выберите в GameScene объект с CinematicTriggerManager
2. Добавьте запись в список Triggers:

   Id:              уникальная строка (по ней сохраняется состояние и код
                    узнаёт об окончании). Пустой Id = событие не сохраняется.
   Trigger Type:    OnDayStart / OnPeriodStart
   Required Day:    день (0 = любой)
   Graph To Play:   CinematicGraph (прямая ссылка на ассет)
   Once:            ✓ — сыграть один раз за партию
   Delay:           задержка в секундах (или случайная: Use Random Delay)
   Execution Mode:  FullControl (блокирует управление) / Background

Ссылайтесь на граф напрямую. CinematicGraphLibrary.LoadGraph(имя) находит
графы из Assets/Data/CinematicGraphs только в редакторе — в билд они попадают
лишь по прямой ссылке или из Resources/.

Текущие события:

   Id               | Когда                 | Граф
   -----------------|-----------------------|----------------------------------
   Tutorial_Day1    | начало дня 1          | Data/CinematicGraphs/Tutorial_Day1
   InspectorVisit   | начало finalDay (30)  | Resources/CinematicGraphs/InspectorVisit

   День визита Инспектора берётся из AIBalanceConfig.finalDay — EndingManager
   выставляет его триггеру при старте, значение в сцене не используется.

Когда срабатывает OnDayStart:

- при смене дня (TimeManager.OnDayChanged);
- после загрузки сцены, когда скрыта заставка дня: MainUIManager вызывает
  CinematicTriggerManager.TriggerDayStart(день). Загрузка всегда начинает день
  заново, а OnDayChanged для первого дня сессии не приходит.

Стол Директора после катсцены начала дня:
  если катсцена сама открыла стол (EventNode OpenDirectorDesk, как в
  туториале) — стандартный старт (стол + приказы) не показывается;
  иначе он показывается после окончания катсцены.

Компонент CinematicTrigger (отдельный объект на сцене) — устаревший путь:
он не сохраняет состояние и не сообщает об окончании. Новые события
заводите только в CinematicTriggerManager.

================================================================================
5. ИМПОРТ JSON-ГРАФА
================================================================================

JSON-файл графа (например, Tutorial_Day1.json) можно импортировать:

1. В Project window: правый клик -> Import JSON
   Или перетащите JSON-файл в папку Assets

2. Выберите CinematicGraph в Project
3. В инспекторе нажмите "Import JSON"
4. Выберите файл Tutorial_Day1.json

Или через меню редактора:
   Tools -> Cinematic Graph Editor
   1. Выберите пустой Graph или создайте новый
   2. Нажмите "Import JSON"
   3. Сохраните как ScriptableObject

Пример структуры JSON:
{
  "name": "Tutorial_Day1",
  "nodes": [
    {"id":"start","t":"start","x":"m1"},
    {"id":"m1","t":"move","wp":"EntryPoint","char":"Director","x":"s1"},
    ...
    {"id":"end","t":"end"}
  ]
}

6. СОХРАНЕНИЕ И РЕАКЦИЯ КОДА НА ОКОНЧАНИЕ КАТСЦЕНЫ
================================================================================

Сохранение:
- В сейв (SaveData.cinematicTriggerStates) пишется, какие события доиграны
  ДО КОНЦА. Отмечается по штатному окончанию графа (CinematicPlayer.OnFinished).
- Если выйти посреди катсцены (Stop() без OnFinished), событие не считается
  доигранным и при загрузке сыграет снова.
- При загрузке состояние восстанавливается до запуска событий начала дня.
  Событие с Once, доигранное в этой партии, больше не запускается.

Реакция кода на окончание:
- Подпишитесь на CinematicTriggerManager.OnTriggerCompleted(string id) и
  сравните id. Так EndingManager после InspectorVisit определяет концовку.
- Не запускайте графы сами и не подписывайтесь на CinematicPlayer.OnFinished
  напрямую: плеер один на всех, и чужой граф его перезапишет.

Ручной запуск события: CinematicTriggerManager.Instance.TriggerNow(id).

================================================================================
7. ТЕСТИРОВАНИЕ
================================================================================

1. Новая игра: после заставки дня 1 запускается туториал
2. Проверьте:
   - Диалог в облачке появляется
   - Персонаж двигается к точкам
   - Курсор меняется во время катсцены
   - Управление блокируется
   - После завершения управление восстанавливается, открыт стол Директора
3. Выйдите в меню посреди туториала и загрузитесь — туториал начнётся заново
4. Доиграйте туториал, выйдите и загрузитесь — туториала нет

Для отладки:
- Включите Debug Log в CinematicTriggerManager и Debug в CinematicPlayer
- Откройте Console для логов
- Запуск события вручную: CinematicTriggerManager.Instance.TriggerNow(id)

8. СОЗДАНИЕ СОБСТВЕННЫХ ГРАФОВ
================================================================================

Через редактор:

1. ПКМ в Project -> Create -> Bureau -> Cinematic -> Cinematic Graph
2. Дважды кликните на графе или нажмите "Open in Editor"
3. В редакторе:
   - ПКМ -> Create Node -> [тип узла]
   - Соедините узлы перетаскиванием
   - Настройте поля в инспекторе
   - Сохраните (Ctrl+S)

Через код:

var graph = ScriptableObject.CreateInstance<CinematicGraph>();
graph.graphName = "My Graph";

var startNode = graph.CreateNode<StartNode>();
var moveNode = graph.CreateNode<MoveToNode>();
moveNode.targetKey = "MyWaypoint";
moveNode.characterID = "Director";

startNode.nextNode = moveNode;
graph.startNode = startNode;

AssetDatabase.CreateAsset(graph, "Assets/MyGraph.asset");

9. НОВЫЕ ВОЗМОЖНОСТИ (обновление)
================================================================================

9.1 Наследование актора (DefaultActor)
--------------------------------------------------------------------------------
StartNode теперь имеет поле characterID, определяющее актера графа.
Этот актер используется по умолчанию для всех последующих узлов.

Как использовать:
- В StartNode укажите characterID (например, "Director")
- В других узлах оставьте characterID пустым или используйте "$Actor"
- CinematicPlayer.ResolveCharacterID() автоматически подставит DefaultActor

9.2 Аудио в EventNode
--------------------------------------------------------------------------------
EventNode поддерживает AudioClip для звуков и музыки:

Поля:
- soundClip: AudioClip для проигрывания звука (PlaySound)
- musicClip: AudioClip для музыки (PlayMusic)
- restorePreviousMusic: флаг для восстановления предыдущей музыки

MusicPlayer получил новый метод:
- PlayOneShotTrack(AudioClip clip): проиграть трек с сохранением предыдущего

9.3 Улучшенный визуальный редактор
--------------------------------------------------------------------------------
CinematicNodeView переработан с цветами и иконками:

Цвета узлов по типам (более насыщенные):
- Start: серый, END: чёрный, Move To: синий
- Say Bubble: бирюзовый, Say Dialog: оранжевый
- Event: красный, Condition: фиолетовый

Иконки в заголовке: ▶ START, ■ END, → Move To, 💬 Say Bubble, ⚡ Event

9.4 Авто-размещение узлов (Auto Layout)
--------------------------------------------------------------------------------
- AddNode(): после создания узел выделяется и прокручивается в центр
- AutoArrange(): DFS-обход графа с расстановкой позиций
  - x увеличивается на 300 для каждого уровня
  - ConditionNode: true-ветвь вниз (+200 по Y), false-ветвь вверх (-200 по Y)
- Кнопка "Auto Layout" на тулбаре

9.5 Paste JSON и автосохранение
--------------------------------------------------------------------------------
Кнопки "Import JSON" и "Paste JSON" на тулбаре:

Импорт JSON:
- Читает файл или буфер обмена
- Импортирует JSON напрямую
- Автоматически выполняет Auto Layout

Автосохранение:
- После импорта граф автоматически сохраняется в:
  Assets/Data/CinematicGraphs/[ИмяГрафа].asset
- Если папка не существует, она создаётся автоматически
- Имя файла очищается от недопустимых символов
- После сохранения папка открывается в Project window

9.6 Структура проекта Cinematic System
--------------------------------------------------------------------------------
Основные файлы системы:

Классы ядра:
- CinematicNode.cs        - базовый класс узла
- CinematicGraph.cs       - граф (наследует ScriptableObject)
- CinematicPlayer.cs      - плеер графа
- SceneObjectRegistry.cs  - регистр объектов сцены
- CharacterRegistry.cs    - регистр персонажей
- CinematicTriggerManager.cs - все события (катсцены), их запуск и сохранение
- CinematicTrigger.cs     - устаревший одиночный триггер (см. раздел 4)

Узлы (Assets/Scripts/Cinematic/Nodes/):
- StartNode.cs, EndNode.cs       - начало/конец
- MoveToNode.cs, TeleportNode.cs - движение
- SayBubbleNode.cs, SayDialogNode.cs - речь
- CallDialogueNode.cs            - вызов диалога
- CameraNode.cs                  - камера
- WaitForSecondsNode.cs, WaitForUIClickNode.cs - ожидание
- ConditionNode.cs               - условие
- EventNode.cs                   - событие
- SpawnCharacterNode.cs          - спавн
- CommentNode.cs                 - комментарий

Редактор (Assets/Scripts/Cinematic/Editor/):
- CinematicEditorWindow.cs   - главное окно
- CinematicGraphView.cs      - GraphView
- CinematicNodeView.cs       - визуальный узел
- CinematicJSONImporter.cs   - импорт JSON
- CinematicJSONExporter.cs   - экспорт JSON
- CinematicGraphInspector.cs - инспектор графа
