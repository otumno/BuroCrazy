## Dialogue System (Система Диалогов)

### Общее описание

**Диалоговая система** — визуальный редактор диалогов на основе нод (Graph View). Позволяет создавать интерактивные диалоги с ветвлениями, условиями и случайными исходами.

### Структура нод:

| Нода | Файл | Описание |
|------|------|----------|
| **DialogueGraph** | `DialogueGraph.cs` | Главный контейнер графа |
| **StartNode** | `StartNode.cs` | Точка входа в диалог |
| **EndNode** | `EndNode.cs` | Завершение диалога |
| **PhraseNode** | `PhraseNode.cs` | Текстовая фраза персонажа |
| **ChoiceNode** | `ChoiceNode.cs` | Выбор игрока (ветвление) |
| **ConditionNode** | `ConditionNode.cs` | Условие перехода |
| **EventNode** | `EventNode.cs` | Вызов игрового события |
| **RandomNode** | `RandomNode.cs` | Случайный выбор |

### Компоненты:

| Компонент | Файл | Описание |
|-----------|------|----------|
| **DialogueGraph** | `DialogueSystem/Data/DialogueGraph.cs` | ScriptableObject граф диалога |
| **SpeakerProfile** | `DialogueSystem/SpeakerProfile.cs` | Профиль персонажа (голос, стиль) |
| **SpecialVisitorDatabase** | `DialogueSystem/SpecialVisitorDatabase.cs` | База запланированных посетителей |
| **DialogueUIConnector** | `DialogueSystem/DialogueUIConnector.cs` | Связь графа с UI |

### Редактор:

```
Assets/Scripts/DialogueSystem/Editor/
├── DialogueGraphView.cs — GraphView для редактирования
├── DialogueEditorWindow.cs — Окно редактора
└── DialogueGraphInspector.cs — Inspector для графа
```

### Пример использования:

1. Создать `DialogueGraph`: **Create → Bureau/Dialogue/Dialogue Graph**
2. Открыть редактор (двойной клик на asset)
3. Добавить ноды и соединить их
4. Сохранить

## Comic Viewer (Просмотр Комиксов)

### Общее описание

**ComicViewerUI** — система для показа интро-комикса при старте новой игры. Поддерживает перелистывание страниц с анимацией и звуками.

### Функционал:

- Отображение страниц комикса как спрайтов
- Анимация перелистывания (3 кадра + вспышка)
- Звуки перелистывания и открытия
- Кнопки: Вперёд, Назад, Закрыть
- Счётчик страниц ("3 / 7")

### UI элементы:

```
[← prev buttons]  [pageImage]  [next buttons →]
               [pageCounterText]
               [close buttons]
```

### Параметры:

| Параметр | Описание |
|----------|---------|
| `pageTurnDuration` | Время перелистывания (0.4сек) |
| `flipFrames` | 3 кадра анимации корешка |
| `flashColor` | Цвет вспышки (белый) |
| `openSound` | Звук открытия |
| `pageTurnSounds` | Звуки перелистывания |

### Компонент:

- `Assets/Scripts/UI/ComicViewerUI.cs`

## Создание Директора (Стартовый Процедурный Нарратив)

### Концепция:

Стартовый тест в виде заполняемой книги (аналог Siren Brante/Tyranny):
- При выборе варианта на каждой странице формируется история становления директора
- Подставляется соответствующая картинка
- В итоге создаётся стартовый initial state (ресурсы, работники, апгрейды, уникальные условия)

### Книга в дальнейшем:

- Доступна в Архиве для повторного просмотра
- Влияет на сюжетные выборы в будущем

---

## Академия Директората (Обучение)

### Цель:

Обучение игрока механикам через абсурдные тестовые сценарии.

### Особенности:

- **Тестовые сценарии:** Симуляция сложных ситуаций
- **Невозможный тест:** Кобаяши Мару нельзя пройти "правильно"
- **Награда за креативность:** За нарушение правил даётся оценка
- **Разблокировка контента:** После обучения открываются новые механики

### Структура сценария:

```csharp
[CreateAssetMenu(fileName = "AcademyScenario_New", menuName = "Bureau/Academy/Scenario")]
public class AcademyScenario : ScriptableObject
{
    public string scenarioId;
    public string scenarioName;
    public string titleText;
    public string descriptionText;
    public Sprite scenarioBackground;
    public AudioClip backgroundMusic;
    public GameDayTrigger trigger; // StartOfGame, NewMechanic, SpecialEvent
    public int requiredDay = 1;
    public bool isRequired = true;
    public List<AcademyStep> steps;
    public AcademyResult successResult;
    public AcademyResult failureResult;
}
```

### Типы этапов (AcademyStepType):

| Тип | Описание |
|-----|----------|
| **Dialogue** | Показать диалог |
| **Choice** | Выбор игрока с последствиями |
| **TimerChallenge** | Выполнить за время |
| **Explanation** | Обучающий текст |
| **Minigame** | Мини-игра |
| **KobayashiMaru** | Невозможный тест |

### Сценарий: Кобаяши Мару (Пример)

**Описание:**
Директор должен обработать 50 клиентов за 30 секунд. Это физически невозможно.

**Параметры:**
```
TimeLimit: 30 seconds
TargetClients: 50
BaseStaff: 1 Intern
Impossible: True
```

**Возможные решения:**

| Путь | Результат |
|------|-----------|
| Честный путь | Провал, "Честность +10" |
| Взятка инспектору | Проход, "Коррупция +20" |
| К клиентам без документов | "Эффективность +30", "Качество -50" |
| Закрыть глаза на нарушения | "Терпение клиентов +20" |

## Концовки Игры

### Варианты концовок (День 30):

| Концовка | Условие | Итог |
|----------|---------|------|
| **"Министр" (Идеальная)** | Ранг = Министр, Коррупция < 10%, Влияние > 1000 | Реформа системы. Город процветает или стонет под гнётом порядка |
| **"Олигарх" (Богатая)** | Денег > $50,000, Коррупция > 50% | Вас уволили, но вы купили остров |
| **"Козел отпущения" (Тюрьма)** | Коррупция = 100%, провалена проверка Ревизора | Арест в прямом эфире. Game Over |
| **"Вечный Клерк" (Средняя)** | Выжили 30 дней, но не достигли вершины | "Контракт продлён ещё на 30 лет" |

## Сюжетные События

### Типы событий:

- **Приход VIP-клиентов:** Мэр, Ревизор, Родственники — в Приёмную директора
- **Проверки:** Ревизоры, инспекторы
- **Случайные события:** Зависят от дня и прогресса

### Диалоговая система:

Диалоги с выбором, влияющим на:
- Взятка / Отказ
- Нарушение закона / Соблюдение
- Сюжетные последствия

### Система текстов:

- Генератор бюрократического текста для документов
- Маскот (советчик игрока) — тексты одобрения/неодобрения
- Процедурная генерация имён, отчётов

---

## Тексты Маскота

### Маскот — советчик игрока:

- **Одобрение:** Положительные фразы при успехе
- **Неодобрение:** Критика при провале
- **Сатира:** Комментарии об абсурдности бюрократии

### Система фраз:

- Генерируемые тексты на основе ситуации
- Библиотека заготовок для разных контекстов

---

## Генератор Бюрократического Текста

### Назначение:

Процедурная генерация документов, отчётов, справок.

### Что генерируется:

- Названия документов
- "Бюрократический язык" (в стиле гос. учреждений)
- Случайные печати и подписи
- Описания к проектам

## Создание Директора (Процесс)

### Этапы:

1. **Выбор фона:** Происхождение директора
2. **Решения:** Ключевые выборы в карьере
3. **Характер:** Формирование личности
4. **Начальные условия:** Ресурсы, персонал, апгрейды

### Влияние на игру:

- Стартовые параметры
- Доступные выборы в диалогах
- Сюжетные развилки
- Бонусы и дебаффы

---

## Интеграция с Геймплеем

### Нарративные выборы влияют на:

| Аспект | Влияние |
|--------|--------|
| Репутация | Отношение NPC |
| Коррупция | Доступ к теневым операциям |
| Навыки | Бонусы к характеристикам |
| Контент | Разблокировка концовок |

### Примеры:

- Взятка ревизору → Коррупция +20
- Помощь родственникам → Уникальные возможности
- Нарушение закона → Новые пути, риск разоблачения
