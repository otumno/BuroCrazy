## Achievements (Система Достижений)

### Общее описание

**AchievementManager** управляет достижениями игрока. При разблокировке показывается toast-уведомление.

### Компоненты:

| Компонент | Файл | Описание |
|-----------|------|----------|
| **AchievementToastUI** | `UI/AchievementToastUI.cs` | Toast-уведомление при разблокировке |
| **AchievementListUI** | `UI/AchievementListUI.cs` | Список всех достижений |
| **AchievementItemUI** | `UI/AchievementItemUI.cs` | Элемент списка достижений |

### Параметры анимации toast:

| Параметр | Значение |
|----------|---------|
| `fadeInTime` | 0.3 сек |
| `displayTime` | 3.0 сек |
| `fadeOutTime` | 0.5 сек |

### Формат текста:

```
"Открыт доступ к архивной записи \"{displayName}\""
```

### Подписки:

```csharp
AchievementManager.Instance.OnAchievementUnlocked += OnUnlockReceived;
```

## Структура Игры и Юзерфлоу

### Основные состояния игры:

```
Launch → Splash Screen → Главное Меню ↔ Офис (Геймплей) ↔ Карта (Мета-игра)
                                    ↓
                              Пауза (ESC)
```

###流程:

1. **Launch:** Splash Screen "Bureau Crazy" → Главное Меню
2. **Главное Меню:**
   - *Новая игра:* Выбор слота → Старт
   - *Загрузка:* Выбор слота → Офис
3. **Gameplay Loop (GameScene):**
   - *Start Of Day:* Панель подготовки (Найм, Приказы)
   - *Action:* Управление Директором и камерой
   - *End Of Day:* Экран итогов (Страйки, Деньги)
   - *Map:* Глобальная стратегия (между днями или по вызову)
4. **Пауза (ESC):** Продолжить, Настройки, Выход в Меню (с автосохранением)

### Переходы между состояниями:

- TransitionManager управляет загрузкой сцен
- Анимация "падающих листьев" / затемнение

## Окно Стола Директора

### Доступ:

Клик на стол директора в офисе

### Содержимое:

- **Кнопка карты** — открывает глобальную стратегию
- **Телефон** — доступ к телефонным службам (Чёрный Телефон)
- **Активные приказы** — список текущих мандатов
- **Активные способности** — доступные абилки директора
- **Документы на подпись** — сложные документы с ошибками

### Документы на подпись:

- Генерируемый "бюрократический текст"
- Игрок должен найти опечатку или взять взятку
- Мини-игра на внимательность

## Окно Бухгалтерии и Апгрейдов

### Доступ:

Через меню или кнопку в HUD

### Секции:

**Бухгалтерия:**
- Подотчётный доход
- Теневой доход
- Расходы (ЗП, мебель, штрафы)
- Итоговый баланс

**Апгрейды:**
- Функциональные (Кофемашина, кресла, автоматы)
- Визуальные (Ковры, картины, цветы)
- Статус покупки

## Окно Отдела Кадров и Настройки Сотрудника

### Доступ:

Через панель или клик на сотрудника

### Функции:

**Найм:**
- Просмотр резюме кандидатов
- Выбор новых сотрудников
- Стоимость найма

**Настройка сотрудника:**
- Назначение на станцию
- Просмотр характеристик (навыки, потребности)
- Перевод на другую роль
- Увольнение

**Должностная инструкция:**
- Общие правила поведения
- Приоритеты задач
- Настройки (приветствия, уборка, приоритеты очередей)
- Что делать с бездомными/буянами

## Окно Карты Города и Карьерной Лестницы

### Описание:

Интерактивная карта для мета-игры

### Элементы:

- **Визуальная карта** с районами
- **Статус районов** (наш/нейтральный/вражеский)
- **Дерево карьеры** — визуальное отображение рангов
- **Influence** — текущий баланс
- **Кнопки действий:** Захват, Защита, Продвижение

### Взаимодействие:

- Клик на район → Информация о стоимости/бонусах
- Подтверждение действий

## Управление Камерой и Зонирование

### Тип управления:

 RTS-style, как Two Point Hospital

### Возможности:

- **Перемещение:** WASD или зажатие ЛКМ + движение
- **Масштабирование:** Колесо мыши
- **Зонирование:** Виртуальные зоны для AI навигации

### Камера директора:

- Следует за игроком
- Или фиксированный вид сверху
