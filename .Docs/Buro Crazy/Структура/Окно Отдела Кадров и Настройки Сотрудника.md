**Цель фичи:** Управление персоналом: найм, увольнение, настройка расписания и тактики.

**Общее описание:** Два режима: Общий список (Картотека) и Детальная настройка (Личное дело).

**UI:**

1. **Панель Кадров (HiringPanelUI):**
   - *Список:* Карточки всех сотрудников (Имя, Роль, Ранг, Стресс).
   - *Фильтры:* Сортировка по Роли, Имени, Рангу.
   - *Найм:* Переключение на доску с резюме кандидатов (ResumePin).
2. **Окно Настройки (ActionConfigPopupUI):**
   - *График:* Выпадающий список смен (Утро, День, Вечер...).
   - *Рабочее место:* Назначение на конкретный стол.
   - *Тактика:* Drag & Drop список приоритетных действий (например, "Игнорировать клиентов", "Только уборка").

**Техническая реализация:**

- HiringManager: Генерирует кандидатов и хранит список штата.
- StaffController: Хранит маску смен (WorkShiftMask) и список действий.
- ActionDatabase: Список всех доступных действий для настройки.
