**Цель фичи:** Визуализировать прогресс игрока (экспансия) и предоставить доступ к стратегическим действиям (захват районов, повышение в должности).

**Общее описание:** Экран разделен на две функциональные зоны. Слева/Центр — карта районов. Справа — вертикальное дерево рангов Директора. Фон затемнен, игра на паузе.

**Описание по деталям:**

1. **Карта Города (City Map):**
   - Изображение города, разбитое на сектора (Районы).
   - *Статусы районов:*
     - 🟢 **Наш:** Иконка дохода, уровень лояльности.
     - ⚪ **Нейтральный:** Иконка замка (можно захватить).
     - 🔴 **Вражеский:** Иконка конкурента (атакует нас).
   - *Взаимодействие:* Клик по району открывает попап с информацией (Тип клиентов, Доход, Цена захвата).
2. **Дерево Рангов (Career Ladder):**
   - Список должностей снизу вверх (Начальник отдела -> ... -> Министр).
   - Текущий ранг подсвечен.
   - Следующий ранг показывает требования (Влияние: 500, Районов: 3).
   - Кнопка "Получить повышение" (активна при выполнении условий).

**UI Элементы:**

- **Счетчик Влияния:** Крупно в углу (валюта для этого экрана).
- **Индикатор Конкурентов:** "Ход конкурента через: X часов" (если карта доступна днем) или пошаговая анимация (если ночью).

**Техническая реализация:**

- **Данные:** MapManager (хранит состояние районов Dictionary<DistrictData, OwnerEnum>) и ProgressionManager (ранг игрока).
- **Визуал:** Спрайтовая карта с интерактивными зонами (Raycast Target alpha mask).
