# Глобальная Карта (Strategy Layer)

---

# **Цель**

Добавить мета-прогрессию и стратегическую глубину.

# **1. Карта Города**

- **Доступ:** Кнопка на столе Директора (рядом с телефоном). Открывает UI MapPanel.
- **Структура:** Город разбит на 10-15 районов (OverlaySprites Nodes).
- **Состояния района:**
  - *Наш:* Дает ебольшой пассивный доход и открывает определенный Архетип клиентов (см. [Архетипы](https://mindeaterteaceremony.yonote.ru/doc/arhetipy-i-vizualizaciya-MwRxaCtnNa)).
  - *Нейтральный:* Можно захватить за Влияние.
  - *Вражеский:* Принадлежит конкурентам ("Департамент Регуляции Хаоса"). Генерирует атаки. Захватывается по условиям (открыты апгрейды) и за доп ресурсы.

# **2. Ресурс "Влияние" (Influence)**

- **Источники:**
  - Идеальное прохождение дня (0 страйков).
  - Успешное решение VIP-событий (см. Док №4).
  - Покупка за "Черную кассу" (повышает Коррупцию).
- **Траты:**
  - Захват районов.
  - Продвижение по службе (Ранги Директора).
  - Защита от атак конкурентов.

# **3. Карьерная лестница (Rank Tree)**

- Визуальное дерево должностей в UI Карты.
- **Ранги:** Региональный менеджер -> Глава Департамента -> Министр.
- **Бонусы:** Каждый ранг открывает новую активную способность (абилку) для Директора:
  - *Уровень 1:* "Ускорение" (заставляет сотрудников работать за столом x2 быстрее).
  - *Уровень 2:* "Выгнать клиента" (ПКМ на клиенте -> удалить без штрафа).
  - *Уровень 3:* "Принудительный овертайм" (восстановить Energy всем сотрудникам ценой Морали).
