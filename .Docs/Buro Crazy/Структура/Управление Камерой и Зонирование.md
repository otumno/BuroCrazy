# Управление Камерой и Зонирование

---

**Цель:** Обеспечить удобную навигацию между "Фронт-офисом" (клиенты) и "Бэк-офисом" (директор), сохраняя ощущение единого здания.

**Общее описание:** Камера ортогональная, 2D. Движение ограничено строго по вертикальной оси Y (или между двумя фиксированными точками).

**Управление:**

1. **Скролл (Mouse Wheel):** Плавно перемещает камеру вверх/вниз.
2. **Кнопка "Глаз" (UI Toggle):** Мгновенный (или быстрый Lerp) переход в противоположную зону.
3. **Зум (Zoom):**
   - *Стандарт:* Виден весь этаж.
   - *Фокус:* При посадке за стол (DirectorDesk) камера плавно приближается (Orthographic Size уменьшается).

**Техническая реализация:**

- **Скрипт:** CameraToggle (уже есть в проекте, требует доработки под скролл).
- **Границы:** minY (Нижний этаж) и maxY (Верхний этаж). Камера не должна показывать "пустоту" за пределами стен.
- **Audio Link:** При переходе на нижний этаж звук толпы (CrowdAudioSource) приглушается (LowPassFilter).
