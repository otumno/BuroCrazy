# Настройка визуалов клиентов

---

## Структура

```
Клиент (префаб)
├── BodySprite (SpriteRenderer) - тело
├── FaceSprite (SpriteRenderer) - лицо
└── OutfitOverlay (SpriteRenderer) - одежда (создать!)
    └── спрайт одежды + цвет

Волосы создаются динамически при спавне:
└── Hair (GameObject)
    └── SpriteRenderer - спрайт причёски + цвет
```

---

## Шаг 1: Настройка префаба клиента

1. Открой префаб клиента в Unity
2. Добавь пустой GameObject `OutfitOverlay` как дочерний
3. Добавь компонент `SpriteRenderer` на OutfitOverlay
4. Установи `Sorting Order` = 1 (над телом)

**ИЛИ** используй скрипт:

1. Добавь компонент `ClientVisualSetup` на любой объект в сцене
2. Назначь префаб клиента в поле `Client Prefab`
3. Нажми `Setup Client Prefab` в контекстном меню

---

## Шаг 2: Создание баз данных

### HairStyleDatabase

1. Правой кнопкой в Project → **Create → Bureau/Databases/Hair Database**
2. Сохрани в `Assets/Resources/Databases/HairDatabase.asset`
3. Открой, нажни **Add Hair Style** несколько раз
4. Для каждой причёски:
   - `hairID` — уникальный ID (например "hair_short_male")
   - `displayName` — название ("Короткие волосы")
   - `frontSprite` — спрайт волос (из Assets/Sprites/Personas/)
   - `allowedColors` — список цветов для рандомизации
   - `allowedArchetypeIDs` — оставь пустым для всех архетипов

### OutfitDatabase

1. Правой кнопкой в Project → **Create → Bureau/Databases/Outfit Database**
2. Сохрани в `Assets/Resources/Databases/OutfitDatabase.asset`
3. Открой, нажни **Add Outfit** несколько раз
4. Для каждой одежды:
   - `outfitID` — уникальный ID (например "suit_male")
   - `displayName` — название ("Костюм")
   - `outfitType` — Casual/Formal/Workwear/Rags/Uniform/Suit
   - `gender` — Male/Female
   - `overlaySprite` — спрайт одежды (одевается поверх тела)
   - `allowedColors` — цвета для рандомизации
   - `allowedArchetypeIDs` — оставь пустым для всех

---

## Шаг 3: Настройка архетипа клиента

1. Создай ClientArchetype: **Create → Bureau/Characters/Client Archetype**
2. Заполни поля:

```
archetypeID: "client_standard"
displayName: "Стандартный клиент"

spriteCollection: (необязательно) свой EmotionSpriteCollection
allowedClothingColors: цвета одежды
allowedOutfitTypes: какие типы одежды разрешены

allowedGoals: [GetCertificate1, GetCertificate2, ...]
thoughtPool: ["Доброе утро!", "Как дела?"]
grumblingLines: ["Это несносно...", "Сколько можно ждать!"]
```

3. Добавь архетип в ArchetypeDatabase

---

## Шаг 4: Проверка настройки

1. Добавь компонент `ClientVisualSetup` на объект в сцене
2. Назначь префаб клиента
3. Нажми `Test Hair Setup` для проверки
4. Запусти сцену — проверь поведение клиентов

## Troubleshooting

**Клиент без волос:**
- Проверь `HairDatabase` в Resources
- Проверь `hairDatabase` ссылку на префабе

**Клиент без одежды:**
- Проверь `OutfitOverlay` объект на префабе
- Проверь `OutfitDatabase` в Resources
- Проверь `outfitDatabase` ссылку на префабе

**Цвета не применяются:**
- Проверь `allowedColors` списки в базах данных
- Проверь `allowColorRandomization` = true

**Волосы не того цвета:**
- Проверь `allowColorReplacement` = true в HairStyleData
- Проверь `allowColorRandomization` = true в OutfitData

## Быстрый старт (минимальная настройка)

1. ✅ Создай `OutfitOverlay` на префабе
2. ✅ Создай `HairDatabase` с одной причёской
3. ✅ Создай `OutfitDatabase` с одним нарядом
4. ✅ Создай `ClientArchetype` с archetypeID = "default"
5. ✅ Добавь архетип в ArchetypeDatabase
6. ✅ Запусти и проверь

Всё должно работать! Цвета будут рандомизироваться из `allowedColors`.
