# Навигация и Поиск Пути

---

**Цель:** Оптимизированное перемещение 100+ агентов в 2D без использования NavMesh (для контроля слоев).

**Реализация:**

1. **Waypoint Graph:**
   - Кастомная система. Объекты Waypoint соединяются в граф при старте (GraphBuilder).
   - PathfindingUtility: Реализует A* (A-Star) или BFS для поиска пути между вейпоинтами.
2. **Agent Mover:**
   - Физическое движение через Rigidbody2D (Kinematic/Dynamic).
   - Локальное избегание: Агенты "расталкивают" друг друга (через коллайдеры) или ждут (Yield), если приоритет ниже.
3. **Зонирование:**
   - LimitedCapacityZone: Логическая зона (Очередь). Управляет входом агентов, чтобы они не толпились в одной точке.
