# Оптимизация 

---

**Цель:** Обеспечить стабильные 60 FPS на Steam Deck при 100+ агентах на сцене.

**Проблемы и Решения:**

1. **Draw Calls (Отрисовка):**
   - *Проблема:* Каждый персонаж состоит из 3-4 спрайтов (Тело, Голова, Одежда, Аксессуар). 100 агентов = 400 Draw Calls.
   - *Решение:* Использовать **Sprite Atlas**. Все части тела должны быть в одном атласе.
2. **Physics 2D:**
   - *Проблема:* Сотни коллайдеров толкаются.
   - *Решение:*
     - У стационарных клиентов (в очереди) переключать Rigidbody2D в Sleep или Kinematic.
     - Использовать упрощенные коллайдеры (Circle) вместо Polygon.
     - Отключить матрицу коллизий для слоев, которые не должны взаимодействовать (например, "Мусор" не сталкивается с "Мусором").
3. **Логика (Update):**
   - *Проблема:* 100 скриптов ClientStateMachine в Update().
   - *Решение:*
     - Использовать **Coroutines** с рандомной задержкой для "тяжелых" проверок (поиск пути, проверка терпения), чтобы размазать нагрузку по кадрам.
     - НЕ ИСПОЛЬЗОВАТЬ FindObjectsByType в Update. Только кэшированные списки (HiringManager.AllStaff).
4. **UI:**
   - Разбить Canvas на под-канвасы (Static, Dynamic). Не перерисовывать весь HUD, если изменилась только одна цифра.
