**Цель:** Сохранять прогресс игрока без потерь данных.

**Формат:** JSON. **Файл:** save_slot_X.json в Application.persistentDataPath.

**Структура Данных (SaveData):**

1. **Глобальные:** День, Деньги, Влияние, Коррупция.
2. **Персонал (StaffSaveData):**
   - Список всех нанятых сотрудников.
   - Для каждого: Имя, Роль, Ранг, Опыт, **Маска Смен (WorkShiftMask)**, Позиция, Текущий Стресс.
   - *Важно:* ActiveActions (тактика) тоже сохраняются.
3. **Мир:**
   - Состояние Апгрейдов (список ID купленных).
   - Состояние Карты (владельцы районов).
   - *Не сохраняем:* Текущих клиентов и мусор (очищаем сцену при загрузке).
