# Система Действий

---


**Цель:** Модульный ИИ, позволяющий легко добавлять новые механики поведения.

**Паттерн:** Command / Strategy.

**Структура:**

1. **StaffAction (ScriptableObject):** Описание действия (Условия, Приоритет, Ссылка на Исполнителя).
2. **ActionExecutor (MonoBehaviour):** Логика выполнения (Корутина). Создается динамически (AddComponent) при запуске действия.
3. **Цикл принятия решений (StaffController):**
   - Раз в N секунд (или по событию) проверяет список доступных activeActions + systemActions.
   - Выбирает действие с наивысшим Score (Приоритет + Модификаторы потребностей).
   - Запускает соответствующий Executor.
