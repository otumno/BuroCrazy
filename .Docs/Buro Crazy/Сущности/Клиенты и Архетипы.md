**Цель фичи:** Создать вариативность геймплея. Игрок должен визуально считывать угрозу ("Ага, идет Бабушка, сейчас очередь встанет") и реагировать.

**Общее описание:** Клиенты спавнятся волнами. Каждый клиент имеет Цель (ClientGoal), параметры Характера и Визуальный Архетип.

**Цели визита (ClientGoal):** 

1. GetCertificate1 / GetCertificate2: Получить справку (Окно 1 или 2).
2. PayTax: Заплатить налог (Касса).
3. DirectorApproval: Подписать документ у Директора (VIP).
4. GetArchiveRecord: Получить выписку (требует запроса в Архив).
5. VisitToilet: Просто зашел в туалет (создает очередь и грязь).

**Архетипы (Archetypes):** 

В текущем коде реализованы через факторы babushkaFactor, suetunFactor, но в UI будут представлены как типы.

1. **Бабушка (The Grandma):**
   - *Визуал:* Платок, тележка.
   - *Статы:* Скорость ОЧЕНЬ низкая. Терпение ОЧЕНЬ высокое (totalPatienceTime x2).
   - *Особенность:* Долго копается в сумке у окна (время обслуживания x1.5).
2. **Суетун / Работяга (The Rusher):**
   - *Визуал:* Кепка, телефон.
   - *Статы:* Скорость высокая. Терпение низкое.
   - *Особенность:* Быстро впадает в ярость (Enraged), если очередь не двигается.
3. **Мажор / VIP (The Rich Kid):**
   - *Визуал:* Костюм, очки.
   - *Особенность:* Платит двойной тариф, но требует идеального сервиса. Если намусорено — уходит сразу.
4. **Пролаза (The Sneak):**
   - *Особенность:* Пытается пролезть без очереди (prolazaFactor). Охранник должен его ловить.

  

#### Логика работы (AI Клиента)

Клиент работает на State Machine (ClientStateMachine). Переходы зависят от внешних факторов (очередь, сотрудник) и внутренних таймеров (терпение).

  `stateDiagram-v2`

`    [*] --> Spawning`

`    Spawning --> MovingToQueue`

`    `

`    state "Ожидание" as Waiting {`

`        MovingToQueue --> InQueue : Взять талон`

`        InQueue --> PatienceCheck : Тик таймера`

`        PatienceCheck --> Enraged : Терпение 0`

`        PatienceCheck --> RagePayment : Нет Кассира`

`    }`

`    `

`    InQueue --> MovingToDesk : Вызов (Call)`

`    MovingToDesk --> BeingServed : Обслуживание`

`    BeingServed --> MovingToCashier : Получил документ`

`    MovingToCashier --> Paying : Оплата`

`    Paying --> Exit : Успех`

`    `

`    Enraged --> Exit : Скандал`

`    RagePayment --> Exit : Бросил деньги`




**Техническая реализация:**

- **Класс:** ClientPathfinding + ClientStateMachine.
- **Генерация:** ClientSpawner настраивает параметры при спавне на основе PeriodSettings.
