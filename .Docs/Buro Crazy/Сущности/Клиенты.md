**Цель фичи:** Вариативность геймплея. Игрок визуально считывает угрозу и реагирует.

## Общее описание

**Клиентская система** управляет всеми посетителями офиса — от момента спавна до ухода.

### Ключевые особенности:
- **Жизненный цикл**: Клиент проходит от спавна до выхода через несколько этапов
- **State Machine**: Машина состояний управляет поведением клиента
- **Терпение**: У каждого клиента есть таймер терпения, по истечении которого он уходит
- **Цели визита**: Разные цели ведут к разным зонам офиса
- **Архетипы**: Влияют на скорость, терпение и поведение клиента
- **Интеграция с зонами**: Клиенты используют LimitedCapacityZone для очередей

### Как клиент влияет на геймплей:
- Клиенты создают очередь — нужно назначать сотрудников к окнам
- "Сложные" клиенты (ярость, замешательство) требуют внимания
- Некоторые клиенты платят больше, некоторые создают беспорядок
- Ушедшие злые клиенты могут оставить негативный отзыв

### Отличия от документации:
⚠️ Архетипы "Бабушка", "Суетун", "Мажор", "Пролаза" — **концептуальные**, в коде реализованы через `babushkaFactor` и `suetunFactor`
- Функция "VIP/двойная оплата" — **не реализована** в текущем коде
- Функция "пролаз без очереди" — **концептуальная**, prolazaFactor не используется активно

## Система Клиентов

### Жизненный цикл клиента

```
Spawning → AtRegistration → AtDesk → AtCashier → Leaving → Destroy
                ↓
         VisitToilet ──────────────────────→ Returning to Goal
                ↓
         WaitingForDocument → AtCashier → Leaving
                ↓
         InsideLimitedZone → DirectorService → Leaving
```

### Клиентские состояния (ClientState)
- `Spawning` - Спавн
- `MovingToGoal` - Движение к цели
- `InQueue` - В очереди
- `WaitingForDocument` - Ожидание документа
- `AtRegistration` - У регистратуры
- `AtDesk1`/`AtDesk2` - У окон 1-2
- `AtCashier` - У кассы
- `InsideLimitedZone` - В зоне директора
- `Leaving` - Уход (успех)
- `LeavingUpset` - Уход (расстройство)
- `Confused` - Замешательство (потерял цель)
- `Enraged` - Ярость

### Цели визита (ClientGoal)
1. **GetCertificate1** - Справка 1 (Окно 1)
2. **GetCertificate2** - Справка 2 (Окно 2)
3. **PayTax** - Оплата налога (Касса)
4. **AskAndLeave** - Спросил и ушёл
5. **VisitToilet** - Туалет
6. **GetArchiveRecord** - Запрос в архив
7. **DirectorApproval** - У директора

## Архетипы

### Факторы влияющие на поведение:
- **babushkaFactor** (0-1): Замедляет, повышает терпение
- **suetunFactor** (0-1): Ускоряет, понижает терпение

### Характеристики:
- `totalPatienceTime` - Время до ухода
- `stressMultiplier` - Множитель стресса
- `noiseTolerance` - Толерантность к шуму
- `corruption` - Склонность к взяткам
