**Цель фичи:** Реализация "бумажной волокиты" — процессов, не связанных с клиентами (открытие регионов, апгрейды, повышения).

## Общее описание

**Система проектных документов** управляет внутренними документами офиса — красными папками, которые создаются при покупке регионов, апгрейдов и повышений.

### Ключевые особенности:

- **Физические объекты**: Красные папки (ProjectDocumentObject) появляются в игровом мире
- **Маршрутизация**: Документы переносятся по особому маршруту (Регистратура → Директор → Бухгалтерия → Архив)
- **Отложенный эффект**: Эффект применяется только когда документ попадает в Архив
- **Интеграция с ИИ**: Стажеры и Офис-менеджер носят эти документы

### Отличие от клиентских документов:

- Клиентские документы создаются клиентами и принадлежат им
- Проектные документы — "красные папки", создаются системой
- Проектные документы имеют свой маршрут и обработку

## Типы Проектных Документов

### 1. RegionUnlockDocument (Открытие региона)

- Создаётся при покупке региона на карте
- Содержит ссылку на RegionData
- При попадании в Архив: регион считается "захваченным"

### 2. UpgradeDocument (Апгрейд)

- Создаётся при покупке мебели/оборудования
- Содержит ссылку на UpgradeData
- При попадании в Архив: апгрейд активируется

### 3. PromotionDocument (Повышение)

- Создаётся при покупке новой должности
- Содержит ссылку на JobTitleData
- При попадании в Архив: игрок получает новую должность

## Жизненный цикл

```
Spawn (на столе директора) → Регистратура → Директор (печать) → Бухгалтерия → Архив → Эффект
```

### Этапы:

1. **Spawn**: Документ создаётся на столе директора (Incoming Stack)
2. **Queue**: Документ попадает в очередь обработки
3. **Service**: Обрабатывается сотрудником (обычно Регистратор)
4. **Director**: Возвращается к директору на подпись
5. **Accounting**: Передаётся Бухгалтеру для проверки
6. **Archive**: Попадает в Архив → эффект применяется

## Интеграция с Map Panel

### Process:

1. Игрок кликает на регион/должность на карте
2. Вместо мгновенного эффекта вызывается `MapPanelUI.SpawnProjectDocument()`
3. Создаётся физический ProjectDocumentObject
4. Документ начинает движение по маршруту
5. Эффект применяется только при попадании в Архив

### UI поля MapPanelUI:

```
Region Doc Prefab → Префаб красной папки
```

## Интеграция с ИИ

### Кто может носить проектные документы:

1. **Intern (Стажёр)** - Может переносить между зонами
2. **OfficeManager (Офис-менеджер)** - Специализируется на этом
3. **Archivist (Архивариус)** - Обрабатывает финальную стадию

### Логика выбора:

- ActionExecutor проверяет тип документа
- Если это проектный документ → приоритет у OfficeManager
- Если OfficeManager недоступен → Intern

## Пример настройки

### Создание RegionData с проектным документом:

1. Создать RegionData ScriptableObject
2. Заполнить поля (ID, Name, UnlockCost)
3. Назначить Region Doc Prefab в MapPanelUI
4. Привязать к ProgressionManager

### Создание префаба красной папки:

1. Создать GameObject с спрайтом красной папки
2. Добавить компонент ProjectDocumentObject
3. Назначить ProjectDocumentDefinition
4. Сохранить как префаб
