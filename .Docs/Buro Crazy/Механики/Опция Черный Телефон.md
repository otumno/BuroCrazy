# Опция Черный Телефон

---

# **Цель**

Дать игроку инструменты для мгновенного решения критических ситуаций за деньги, когда микроменеджмент не справляется.

# **1. Интерфейс (UI/UX)**

- **Точка входа:** cпрайт-кнопка дискового телефона на столе Директора (кликом) ИЛИ кнопка "SOS" в панели управления (DirectorControlPanelUI).
- **Окно:** Немодальное окно (игра не ставится на паузу, но звуки приглушаются). Стилизовано под телефонную книгу.
- **Вкладки:**
  1. *Экстренные службы (Static)* — фиксированные цены, мгновенный эффект.
  2. *Кадровый резерв (Dynamic)* — список из 6 случайных временных сотрудников по возможности закрывающих все критические позиции.

# **2. Экстренные службы (Unit Types)**

- **ОМОН (Security Squad):**
  - *Цена:* Высокая.
  - *Действие:* Спавн 2-х усиленных GuardMovement.
  - *Логика:* Игнорируют патруль. Бегут к ближайшему клиенту со статусом Enraged или Chasing. При контакте мгновенно удаляют клиента (анимация "выноса").
  - *Длительность:* один период + время с начала периода найма.
- **Спец-Клининг (Bio-Hazard Team):**
  - *Цена:* Средняя.
  - *Действие:* Спавн 3-х безымянных ServiceWorkerController со скоростью x2.
  - *Логика:* Приоритет на Puddle и Trash. 
  - *Длительность:* один период + время с начала периода найма.
- **Клоун (Chaos Control):**
  - *Цена:* Средняя.
  - *Действие:* Спавн NPC Клоун (не StaffController). Патрулирует по вейпоинтам WaitingZone.
  - *Аура:* Каждые 5 секунд восстанавливает 20% терпения (patience) всем клиентам в радиусе 10 метров.
  - *Риск:* Шанс 5% при каждом такте создать MessPoint (конфетти/грязь).
  - *Длительность:* один период + время с начала периода найма. Разбрасывает “бананы” с шансом подскальзывания 90%.
  - *Оссобенность:* Во время работы клоуна играет специфическая музыка.

# **3. Временный персонал (Temp Staff)**

- **Генерация:** Использует HiringManager.GenerateNewCandidates, но скрывает имена ("Сотрудник #492") и блокирует прокачку.
- **Ограничения:** Нельзя назначить тактику в ActionConfigPopupUI. Работают только 1 смену, затем исчезают.
- **Экономика:** Стоимость найма = стоимость периода сотрудника * 1.5 * количество периодов.

# **Техническая реализация:**

- **Менеджер:** PhoneManager (генерирует сменщиков через HiringManager, спавнит спец-юнитов).
- **Ограничения:** Сменщики имеют флаг isTemporary, не сохраняются в сейв-файл и исчезают в OnPeriodChanged (Night).

# **Бэклог идей:**

- "Звонок другу" (подсказка).
- "Заказать пиццу" (восстановить энергию всем сотрудникам).
