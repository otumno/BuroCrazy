# Прогрессия Директора и Офиса

---

# 1. Карьерная Лестница (The Rank Tree)

Дерево прокачки самого Директора. Отображается на Карте Города.

- **Уровни:**
  1. *Начальник отдела* (Старт).
  2. *Региональный директор.*
  3. *Глава Департамента.*
  4. *Замминистра.*
  5. *Министр.*
- **Требования:** Для повышения нужен определенный уровень Влияния и количество захваченных Районов.

# 2. Активные Способности (Director Skills)

Каждый ранг дает Директору новые возможности взаимодействия в офисе (через контекстное меню на клиентах/сотрудниках):

- **Ранг 1:** "Личное ускорение" — Директор работает за столом на 50% быстрее.
- **Ранг 2:** "Выгнать клиента" — Возможность удалить любого клиента без штрафа (используется против Скандалистов).
- **Ранг 3:** "Крик начальника" — Восстанавливает Энергию сотрудникам в радиусе, но сильно снижает их Мораль.
- **Ранг 4:** "Взятка ревизору" — Возможность отменить проверку за деньги.

# 3. Апгрейды Офиса (Office Upgrades)

Покупка мебели и оборудования за Деньги.

- **Функциональные:**
  - *Кофемашина:* Сотрудники быстрее восстанавливают Энергию.
  - *Удобные кресла:* Сотрудники медленнее теряют Комфорт/Здоровье.
  - *Автомат с талонами:* Упорядочивает очередь (снижает хаос).
- **Визуальные:** Ковры, картины, цветы. Влияют на общий престиж (прирост Влияния).
