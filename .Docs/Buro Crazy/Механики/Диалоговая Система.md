**Цель фичи:** Интерактивные диалоги с клиентами, NPC и сюжетные события с визуальным сопровождением.

## Общее описание

**Диалоговая система** — это графовая система интерактивных диалогов, используемая для взаимодействия директора с клиентами, NPC и для сюжетных событий.

### Ключевые особенности:

- **Графовая структура**: Диалог строится как направленный граф нод
- **Ветвление**: ChoiceNode позволяет создавать разветвлённые диалоги с условиями
- **Условия**: Система флагов (SetFlag) для сохранения состояния диалога
- **Визуальное сопровождение**: Поддержка изображений и фонов
- **Аудио**: Звуки при появлении реплик и событиях
- **Интеграция с геймплеем**: EventNode может изменять деньги, выдавать страйки

### Где используется:

- Диалоги с клиентами (при вызове в кабинет)
- Сюжетные события
- Инструктаж при найме
- События проверки

### Ограничения:

- Диалог блокирует геймплей (пауза)
- Требует настроенный UI (DialogueUIConnector)
- Изображения должны быть в проекте как Sprite

## Структура Нод

### Start Node (СТАРТ)

- Начальная точка диалога
- Поле `Default Background`: Фон по умолчанию для всех последующих нод
- Поле `Start Sound Override`: Кастомный звук начала диалога
- Выход: `nextNode`

### Phrase Node (ФРАЗА)

- Базовая реплика персонажа
- Поля:
  - `Speaker ID`: 'Director', 'Client' или ID из базы NPC
  - `Appear Sound`: Звук "вжик" при появлении
  - `Voice Clip`: Спец. озвучка
  - `Speaker Portrait`: Спец. портрет (переопределяет дефолтный)
  - `Node Image`: Изображение для показа в этой ноде
- Выходы: `nextNode`, `choices` (динамические)

### Choice Node (ВЫБОР)

- Ветвление диалога кнопками
- Поля:
  - `Query Text`: Вопрос игроку
  - `Options`: Список вариантов с условиями
  - `Node Image`: Изображение для показа
- Условия (Condition):
  - `Key`: Ключ флага (например: 'MONEY', 'MET_INSPECTOR')
  - `Op`: Оператор (>=, <=, ==, !=)
  - `Value`: Значение для сравнения

### Event Node (СОБЫТИЕ)

- Изменение состояния игры
- Поля:
  - `Set Flag Key`: Имя флага
  - `Set Flag Value`: Значение
  - `Add Money`: Добавить/отнять деньги
  - `Add Strike`: Выдать страйк директору
  - `Notification Text`: Текст окна "РЕЗУЛЬТАТ"
  - `Sound Effect`: Звук события
  - `Node Image`: Изображение для показа
- Выход: `nextNode`

### End Node (КОНЕЦ)

- Завершение диалога
- Выход: Нет (диалог закрывается)

### Random Node (РАНДОМ)

- Случайный переход к одной из нод
- Выходы: `randomOutputs`

### Condition Node (УСЛОВИЕ)

- Проверка флага и выбор ветки
- Выходы: `trueNode`, `falseNode`

## Логика Изображений

### Приоритет отображения:

1. Изображение в конкретной ноде (Phrase/Choice/Event)
2. Дефолтный фон из StartNode
3. Ничего (если не указано)

### Настройка UI:

```
DialogueView (DialogueUIConnector)
├── Panel
├── DirectorPortraitImage
│   └── DirectorPortraitFrame (Image)
├── ClientPortraitImage
│   └── ClientPortraitFrame (Image)
├── DialogueTextText
├── DirectorNameText
├── NextButton
├── ChoiceContainer
└── NodeImageContainer (GameObject)
    ├── NodeImageFrame (Image) - рамка
    └── NodeImageDisplay (Image) - контент
```

**Настройка рамок портретов:**

- Frame должен быть дочерним объектом портрета
- Frame должен быть выше в иерархии (Z-index)
- Использовать 9-slice спрайт для рамки

## Техническая реализация

### Ключевые файлы:

- `Assets/Scripts/DialogueSystem/Data/DialogueNode.cs` - базовый класс
- `Assets/Scripts/DialogueSystem/Data/PhraseNode.cs` - реплика
- `Assets/Scripts/DialogueSystem/Data/ChoiceNode.cs` - выбор
- `Assets/Scripts/DialogueSystem/Data/EventNode.cs` - событие
- `Assets/Scripts/DialogueSystem/Data/StartNode.cs` - старт с фоном
- `Assets/Scripts/DialogueSystem/DialogueUIConnector.cs` - UI связи
- `Assets/Scripts/Managers/DialogueUIManager.cs` - логика показа
- `Assets/Scripts/DialogueSystem/Editor/DialogueGraphView.cs` - редактор

### Вызов диалога:

```csharp
DialogueUIManager.Instance.StartDialogue(dialogueGraph, client);
```

## Теги и ID

| Тег | Значение |
|----|----|
| Director | Речь директора |
| Client | Речь клиента |
| NPC:{ID} | Речь NPC по ID |

## Пример настройки диалога

1. Создать ScriptableObject DialogueGraph
2. Добавить ноды через контекстное меню (правая кнопка в редакторе)
3. Соединить ноды портами
4. Настроить StartNode: задать Default Background
5. Настроить изображения в конкретных нодах при необходимости
6. Сохранить DialogueGraph asset
