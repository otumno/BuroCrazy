# Время: Сутки и Периоды

---

Цель фичи:

Создать динамику геймплея, разделить игру на фазы "Планирование" и "Экшн", обеспечить смену сложности (волны клиентов).

Общее описание:

Игровой процесс разбит на Дни. Каждый день состоит из набора Периодов (Утро, День, Обед, Вечер, Ночь). Время внутри периода течет в реальном времени, но может быть ускорено или поставлено на паузу.

**Описание по деталям:**

1. 
   **Структура Дня:** Задается через ScriptableObject CalendarDay -> PeriodSettings
2. **Смена Периода:** Происходит автоматически по таймеру. При смене:
   - Меняется освещение (LightingPreset)
   - Меняется смена сотрудников (кто-то уходит домой, кто-то приходит)
   - Меняются параметры спавна клиентов (кривые spawnRate, clientCount)
3. **Ночная фаза:** Особый период. Офис пустеет, открывается возможность перейти к Глобальной Карте.
     

   #### Логика работы (Смена Периодов)

   ClientSpawner выступает в роли главного метронома.
   1. **Тик:** Update() увеличивает periodTimer.
   2. **Переход:** Когда таймер > durationInSeconds, индекс периода смещается.
   3. **Событие OnPeriodChanged:**
      - Lighting: Запускает корутину FadeLight для смены цвета.
      - Staff: Проверяет WorkShiftMask всех сотрудников. Те, чья смена кончилась -> EndShift(). Те, чья началась -> StartShift().
      - Music: MusicPlayer меняет трек (Дневной -> Ночной).

**UI:**

- **Часы:** Текстовый таймер в HUD (09:00 -> 18:00) или иконка текущего периода (IconClockUI).
- **Сплеш-скрин:** Экран "ДЕНЬ X" перед началом смены (DaySplashScreenController)15.
- **Кнопка:** "Начать день" / "Продолжить" в StartOfDayPanel.

**Техническая реализация:**

- **Контроллер:** ClientSpawner управляет таймером periodTimer и индексом периода currentPeriodIndex.
- **Типы периодов:** CalendarDayPeriodType (Flags Enum: Morning, EarlyDay, Noon...)16.
- **Настройки:** PeriodSettings хранит длительность, цвет света и кривые спавна.
- **События:** ClientSpawner.OnPeriodChanged оповещает другие системы (свет, часы, музыку)17.
- **Свет:** TimeOfDaySpriteController и корутина ManageLocalLightsSmoothly плавно меняют цвет спрайтов и включают лампы 18,19.
