## Общее описание

**Система износа** управляет состоянием мебели и оборудования офиса. Предметы имеют прочность, которая снижается со временем и использованием.

### Ключевые особенности:

- **Прочность**: 0-100%, снижается при использовании
- **Визуальные состояния**: Целый → Потертый → Сломанный
- **Влияние на геймплей**: Сломанные предметы работают хуже или не работают
- **Ремонт**: Уборщик может чинить мелкие поломки, капитальный ремонт — внешняя бригада

### Что подвержено износу:

- Рабочие столы (ServicePoint)
- Стулья ожидания (WaitingChair)
- Диваны отдыха (RestArea)
- Оборудование (Компьютер, Кофемашина и т.д.)
- Окна и двери

## Состояния Предметов

### Три состояния прочности:

| Состояние | Прочность | Влияние |
|----|----|----|
| **Целый (Intact)** | 100-70% | Полная эффективность (1.0x) |
| **Потертый (Worn)** | 70-30% | Сниженная эффективность (0.7x) |
| **Сломанный (Broken)** | <30% | Не работает или минимальная эффективность (0.1x) |

### Влияние на разные объекты:

**ServicePoint (Рабочий стол):**

- Целый: Нормальная скорость обслуживания
- Потертый: Замедление на 30%
- Сломанный: Клиенты не могут обслуживаться

**WaitingChair (Стулья):**

- Целый: Восстановление терпения нормальное
- Потертый: Восстановление терпения замедлено
- Сломанный: Стул недоступен

**RestArea (Диван отдыха):**

- Целый: Восстановление Energy 100%
- Потертый: Восстановление Energy 70%
- Сломанный: Не восстанавливает Energy

## Техническая реализация

### OfficeObjectDurability Component:

```csharp
public class OfficeObjectDurability : MonoBehaviour
{
    [Header("Настройки прочности")]
    public float currentDurability = 100f;
    public float maxDurability = 100f;
    
    [Header("Пороги состояний")]
    [Range(0, 100)] public float wornThreshold = 70f;
    [Range(0, 100)] public float brokenThreshold = 30f;
    
    [Header("Визуализация")]
    public SpriteRenderer mainRenderer;
    public Sprite intactSprite;
    public Sprite wornSprite;
    public Sprite brokenSprite;
    
    [Header("Деградация")]
    public float degradationPerUse = 5f;
    public float timeBasedDegradation = 0.5f; // за час игрового времени
    
    public bool IsUsable() => currentDurability > brokenThreshold;
    public float GetEfficiencyMultiplier() => GetEfficiencyForDurability();
    public void Degrade(float amount) => currentDurability = Mathf.Max(0, currentDurability - amount);
    public void Repair(float amount) => currentDurability = Mathf.Min(maxDurability, currentDurability + amount);
}
```

### Влияние на efficiency multiplier:

```csharp
// В StaffController или клиентском коде
var durability = workstation.GetComponent<OfficeObjectDurability>();
if (durability != null && !durability.IsUsable())
{
```

## Источники Деградации

### 1. Использование (Use-based)

- Клиент сел на стул → -5 durability
- Клерк работает за столом → -2 durability
- Диван использован для отдыха → -10 durability

### 2. Время (Time-based)

- Предметы изнашиваются со временем
- 0.5 durability за час игрового времени
- Суммируется с использованием

### 3. Вандализм

- Разозлённые клиенты (Enraged) могут ломать предметы
- Кражы могут повредить оборудование

## Система Ремонта

### Микро-ремонт (Уборщик)

**Когда**: Мелкие поломки (потертость)

**Как**:

```csharp
// ServiceWorkerController
public void PerformRepair(ServicePoint target)
{
    var durability = target.GetComponent<OfficeObjectDurability>();
    if (durability != null && durability.currentDurability < durability.wornThreshold)
    {
        durability.Repair(30f);
        ShowRepairEffect(target.transform.position);
    }
}
```

**Время**: 10-30 секунд в зависимости от повреждения

### Макро-ремонт (Бригада)

**Когда**: Капитальные поломки или пожар

**Процесс**:

1. Игрок вызывает "Ремонтную Бригаду" (открывается с Промышленным районом)
2. Создаётся ProjectDocumentObject "Ремонт"
3. Документ проходит маршрут
4. При попадании в Архив → все предметы восстанавливаются до 100%

**Стоимость**: Зависит от количества сломанных предметов

## Интеграция с Геймплеем

### Клиенты:

- Сломанные стулья = нет восстановления терпения
- Клиенты воруют сломанные вещи чаще

### Сотрудники:

- Работают медленнее у сломанных столов
- Сломанный диван = нет восстановления Energy

### Экономика:

- Ремонт стоит денег
- Неработающие столы = потеря дохода
