# Академия Директората

---

**Цель фичи:** Обучение игрока механикам через абсурдные тестовые сценарии.

## Общее описание

**Академия** — это система обучения, которая запускается в определённые моменты игры (начало игры, новые механики). Включает тест Кобаяши Мару — тест, который невозможно пройти честно.

### Ключевые особенности:
- **Тестовые сценарии**: Симуляция сложных ситуаций
- **Невозможный тест**: Кобаяши Мару нельзя пройти "правильно"
- **Награда за креативность**: За нарушение правил даётся оценка
- **Разблокировка контента**: После обучения открываются новые механики

```csharp

{
    public string stepId;
```

## Типы Этапов (AcademyStepType)

| Тип | Описание | Параметры |
|-----|----------|-----------|
| **Dialogue** | Показать диалог | dialogueGraphId |
| **Choice** | Выбор игрока | choices (с последствиями) |
| **TimerChallenge** | Выполнить за время | targetAction, timeLimit |
| **Explanation** | Обучающий текст | text, continueButton |
| **Minigame** | Мини-игра | minigameType, parameters |
| **KobayashiMaru** | Невозможный тест | impossibleParameters |

## Сценарий: Кобаяши Мару (Пример)

### Описание:
Директор должен обработать 50 клиентов за 30 секунд. Это физически невозможно. Цель — проверить, нарушит ли игрок правила.

### Параметры сценария:
```
TimeLimit: 30 seconds
TargetClients: 50
BaseStaff: 1 Intern
Impossible: True
```

### Возможные "решения" игрока:

1. **Честный путь** → Проваливает тест, но получает "Честность +10"
2. **Взятка инспектору** → Проходит, но "Коррупция +20"
3. **Отправить всех к кассе без документов** → "Эффективность +30", "Качество -50"
4. **Закрыть глаза на нарушения** → "Терпение клиентов +20"

## Интеграция с Системой

### AcademyManager:

```csharp
public class AcademyManager : MonoBehaviour
{
    public static AcademyManager Instance { get; private set; }
    
    [Header("Данные")]
    public List<AcademyScenario> allScenarios;
    
    [Header("Состояние")]
    public AcademyScenario currentScenario;
    public AcademyStep currentStep;
    public int currentStepIndex;
    
    [Header("UI")]
    public AcademyUI academyUI;
    
    public void StartScenario(string scenarioId);
    public void StartScenario(AcademyScenario scenario);
    public void CompleteStep(AcademyStep step, bool success);
    public void FinishScenario(AcademyResult result);
    public void SkipScenario(string scenarioId); // Для отладки
}
```

### Точки запуска:

1. **StartOfGame**: "Вводный курс молодого директора"
   - Обучение основам (окна, клиенты, очередь)
   - 3 простых этапа

2. **NewMechanic**: При разблокировке новой механики
   - Пример: "Документооборот" → сценарий про Архив

3. **SpecialEvent**: Особые события
   - "Проверка из центра"
   - "Народный протест"
