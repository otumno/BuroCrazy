---

**Цель фичи:** Создавать бесконечный, смешной и правдоподобный "канцелярский шум" для документов, которые подписывает игрок. Текст должен выглядеть важным, но быть бессмысленным.

**Алгоритм Генерации (BureaucraticTextGenerator):** Текст собирается из случайных фрагментов по формуле: [Вступление] + [Номер] + [Тема] + [Условие] + [Глагол] + [Объект] + [Уточнение].

**Примеры фрагментов:**

- *Вступление:* "Ввиду ретроградного Меркурия...", "Согласно параграфу 7-БИС...".
- *Тема:* "...о регламентации оборота скрепок...", "...о запрете хорошего настроения...".
- *Глагол:* "...надлежит незамедлительно запретить...", "...считать целесообразным игнорировать...".
- *Объект:* "...ношение носков разного цвета.", "...тихое напевание под нос.".

**Техническая реализация:**

- Статический класс со списками строк (string[]).
- Метод GenerateParagraph() возвращает отформатированный текст с тегами Rich Text (для выделения ошибок).
