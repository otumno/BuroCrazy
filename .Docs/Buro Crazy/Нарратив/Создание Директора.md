# Создание Директора

---

**Цель фичи:** Создание уникального персонажа игрока через серию выборов (в стиле The Life and Suffering of Sir Brante).

## Общее описание

**Создание директора** — это книга-опросник, формирующая начальные ресурсы, историю и характеристики игрока.

### Ключевые особенности:
- **Книга-опросник**: Серия страниц с выбором
- **Влияние на старт**: Начальные деньги, репутация, доступ к механикам
- **Нарративная интеграция**: Выбранные ответы формируют предысторию
- **Уникальный директор**: Каждый игрок создаёт своего директора

### BookChoice:

```csharp
[System.Serializable]
public class BookChoice
{
    public string choiceId;
    public string choiceText;
    public Sprite choiceIllustration;
    
    [Header("Последствия")]
    public int moneyChange;      // Изменение начальных денег
    public int influenceChange;  // Изменение начального влияния
    public float corruptionStart; // Начальная коррупция
    public string backstorySnippet; // Фрагмент предыстории
    
    [Header("Открывает")]
    public List<string> unlockedFeatures; // Что открывает этот выбор
    public List<string> lockedFeatures;   // Что закрывает
    
    [Header("Следующая страница")]
    public string nextPageId; // null = конец книги
    public int nextPageNumber; // Для быстрого перехода
}
```

## Интеграция с SaveData

### При создании новой игры:

```csharp
// DirectorCreationBookUI.ApplyResults()
public void ApplyResults()
{
    SaveData data = new SaveData();
    
    data.money = 1000; // База + sum(choice.moneyChange)
    data.influence = sum(choice.influenceChange)
    data.startingCorruption = choice.corruptionStart // Первый выбор
    
    // Открытые features
    foreach (var choice in selectedChoices)
    {
        foreach (var feature in choice.unlockedFeatures)
        {
            data.unlockedFeatureIDs.Add(feature);
        }
    }
    
    // Генерируем backstory
    data.backstory = GenerateBackstory(selectedChoices);
}
```

## Генерация Предыстории

```csharp
public string GenerateBackstory(List<BookChoice> choices)
{
    StringBuilder sb = new StringBuilder();
    
    sb.AppendLine("=== ПРОШЛОСТЬ ДИРЕКТОРА ===");
    sb.AppendLine();
    
    foreach (var choice in choices)
    {
        if (!string.IsNullOrEmpty(choice.backstorySnippet))
        {
            sb.AppendLine(choice.backstorySnippet);
            sb.AppendLine();
        }
    }
    
    return sb.ToString();
}
```

### Долгосрочные эффекты:

**Происхождение: Из низов**
- Сниженная цена найма бедных клиентов
- Доступ к архетипу "Бабушка" с бонусами
- +10% терпение у клиентов-бедняков

**Происхождение: Из аристократии**
- +20% чаевые от VIP клиентов
- Доступ к архетипу "Мажор"
- Штрафы от бедных клиентов

**Прошлое: Бухгалтер**
- Accounting роль доступна сразу
- +10% к официальному доходу
- Можно открыть "Теневую бухгалтерию"
