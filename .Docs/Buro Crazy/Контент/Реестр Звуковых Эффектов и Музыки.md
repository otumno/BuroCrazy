# Реестр Звуковых Эффектов и Музыки

---

**Цель:** Создать "сочную" звуковую картину (Audio Feedback).

**1. Музыка (MusicPlayer):**

- MenuTheme: Спокойный джаз / Лифтовая музыка.
- Gameplay_Day_Calm: Ритмичный стук печатных машинок + бас.
- Gameplay_Day_Chaos: Индастриал, ускоренный темп (включается, когда > 20 клиентов).
- Director_Office: Приглушенная, "дорогая" версия темы.

**2. SFX Интерфейса:**

- UI_Hover: Тихий щелчок.
- UI_Click: Звук старой клавиатуры или ручки.
- UI_Stamp_Approve: Громкий, сочный удар печати.
- UI_Stamp_Reject: Резкий, неприятный звук.
- UI_Money: Звон монет / Шуршание купюр.

**3. SFX Мира:**

- Footsteps: Шаги (разные для паркета и кафеля).
- Voices_Gibberish: "Бла-бла-бла" (высокий питч для женщин/детей, низкий для мужчин/охранников).
- Rage_Scream: Крик скандалиста.
- Door_Bell: Колокольчик при входе клиента.

**Техническая реализация:**

- Использовать AudioSource.PlayClipAtPoint для 3D звуков.
- MixerGroups: Master, Music, SFX, Ambience.
