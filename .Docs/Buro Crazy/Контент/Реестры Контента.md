# Реестры Контента

**Цель:** Централизованное хранение всех списков (ScriptableObjects) для удобного баланса и локализации.

**Список Баз Данных:**

1. **RoleData:** Базовые статы для каждой роли (Скорость, Стресс, Префаб, Спрайты).
2. **RankData:** Дерево прокачки (Требования опыта, Зарплата, Открываемые действия).
3. **ActionDatabase:** Все возможные действия (StaffAction) для назначения в тактике.
4. **ThoughtCollection:** Списки фраз для бабблов, разделенные по категориям (Idle, Work, Rage) и уровням стресса (Зеленый/Желтый/Красный).
5. **NameGeneratorDB:** Списки Имен, Фамилий и Отчеств для генерации сотрудников.
